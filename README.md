# Banking Crisis Early Warning System (EWS)

Predicting systemic banking crisis onsets across a 24-country emerging
market panel (1970-2025), using IMF Laeven & Valencia crisis labels and
World Bank macro/financial indicators. Companion project to a Currency
Crisis EWS built on the same methodology.

## Pipeline

```
src/01_prepare_crisis_labels.py   -> crisis onset labels (Laeven & Valencia)
src/02_merge_indicators.py        -> merge macro indicators, apply 1-year lag
src/03_build_folds.py             -> crisis-balanced country folds for CV
models/04_train_tabular_models.py -> LogReg, RF, XGBoost, LightGBM (nested CV)
models/05_train_lstm.py           -> LSTM (nested CV)
```

Run in order from the repo root:

```bash
pip install -r requirements.txt
python src/01_prepare_crisis_labels.py
python src/02_merge_indicators.py
python src/03_build_folds.py
python models/04_train_tabular_models.py
python models/05_train_lstm.py
```

## Data

Place raw source files in `data/raw/`:
- `SYSTEMIC_BANKING_CRISES_DATABASE_2026.xlsx` - IMF Laeven & Valencia database
- `P_Data_Extract_From_World_Development_Indicators.xlsx` - World Bank Databank export
- `exchange_rate_depreciation.csv` - country-year FX depreciation (%)

Processed panels land in `data/processed/`. Results land in `results/`.

**Known gap:** the World Bank export currently in `data/raw/` only covers the
original 16 countries (the panel was later expanded to 24). `data/processed/
banking_crisis_model_ready.csv` is therefore currently supplied directly
(already merged and independently verified against both source datasets)
rather than fully regenerated by `02_merge_indicators.py` end-to-end. To
make the pipeline reproducible from raw sources only, re-export World Bank
indicators for all 24 countries (same 8 indicators, same Databank process)
into `data/raw/`, then `02_merge_indicators.py` will regenerate this file
directly.

## Countries (24)

Argentina, Brazil, Mexico, Chile, Colombia, Turkey, Russia, Poland, Hungary,
Egypt, Nigeria, Morocco, India, Indonesia, Thailand, Philippines, Costa Rica,
Ecuador, Ghana, Kazakhstan, Kenya, Ukraine, Uruguay, Viet Nam.

## Target

`crisis_t = 1` in the first year of a systemic banking crisis episode
(onset only - not every year the crisis lasted). 46 onsets across 1,320
country-years (~3.5% positive class).

## Features (all lagged 1 year, t-1, to avoid look-ahead bias)

GDP growth, domestic credit to private sector (% GDP), inflation, reserves
(months of imports), current account balance (% GDP), exchange rate
depreciation. Interest rate spread and bank capital/NPL ratios were
collected but excluded - too sparse (48-68% missing at crisis onsets) to
trust in a 46-event sample. BIS's official credit-to-GDP gap was also
tested and excluded: only 10/29 onsets (in the earlier 16-country version)
had coverage, concentrated in specific countries, which would have biased
the model rather than helped it.

## Methodology notes worth knowing before reusing this code

- **1-year lag**: every feature reflects information from year t-1, paired
  with the crisis label at year t. This is what makes it a genuine early
  warning system rather than a same-year classifier.
- **Country-grouped folds, not random splits**: a random row split would
  leak information across years of the same crisis episode. Folds are
  built so entire countries move together, and are balanced so each fold
  has a similar number of crisis onsets (not just a similar number of
  countries).
- **Nested cross-validation**: within each outer fold, hyperparameters,
  architecture choices, and imputation statistics are selected using an
  *inner* train/validation split carved out of the training countries
  only. The outer test fold is touched exactly once, to record the final
  score - never during tuning.
- **Leakage-safe missing value handling**: imputation medians are computed
  using an *expanding, past-only* window (never a country's own future
  years), and any cross-country fallback is computed from train-fold
  countries only. An earlier version of this pipeline used whole-series
  medians and backward-fill, which was caught and fixed after finding it
  would have leaked information into roughly half the crisis onsets - a
  good example of why this check matters.

## Results (nested 6-fold country-grouped CV)

| Model | AUC | PR-AUC |
|---|---|---|
| LSTM | 0.646 ± 0.052 | 0.119 ± 0.063 |
| LightGBM | 0.670 ± 0.068 | 0.110 ± 0.050 |
| Logistic Regression | 0.621 ± 0.126 | 0.108 ± 0.064 |
| XGBoost | 0.654 ± 0.091 | 0.098 ± 0.038 |
| Random Forest | 0.611 ± 0.090 | 0.088 ± 0.042 |
| Basel III benchmark (credit-to-GDP level) | 0.522 ± 0.035 | 0.056 ± 0.022 |

Random-guess PR-AUC at this crisis prevalence (~3.5%) is ~0.035, so every
model meaningfully beats both random guessing and the simple Basel III
rule. LSTM and LightGBM are close leaders; the gap between them is small
relative to the standard deviation given only 46 total crisis events, so
neither should be over-claimed as definitively best.
